## Vulnérabilités connues et acceptées (au 18/10/2026)

`npm audit` signale :

- **Production (modérées)** : `react-router` 6.x — redirection ouverte via `\` dans `<Link>`/`useNavigate` et désérialisation en rendu serveur. **Non exploitable ici** : l’app est une SPA sans rendu serveur, et aucun lien n’est construit à partir d’une saisie utilisateur. **Règle de code : ne jamais passer une URL venant d’un utilisateur à `Link`/`navigate`.** Le correctif demande react-router 7 (hors stack imposée).
- **Développement (haute)** : `braces` (via Tailwind 3.4 → chokidar/micromatch). Déni de service par motif de fichier très imbriqué, **uniquement pendant le build sur la machine du développeur**, rien n’est livré au navigateur. Aucune version corrigée n’existe. À réévaluer en passant à Tailwind 4.

Le seuil du projet (`npm audit --omit=dev --audit-level=high`) est respecté. À rejouer à chaque phase.
